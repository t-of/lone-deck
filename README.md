# LONE DECK — 必ず解けるひとりトランプ

昔からあるひとりトランプ「ソリティア（クロンダイク）」。配られる札は必ず解ける並びだけで、何手でも戻せる。毎日 1 つの「今日の配り」は誰でも同じ札なので、手数と時間を比べられる。

## 🔗 リンク

- 遊ぶ: https://lone-deck.t-of.workers.dev/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

クロンダイク（1 枚めくり、山は何度でも戻せる）。

1. 下の 7 つの列から札を動かして、上の 4 つの置き場に、マークごとに A・2・3 … K と積む。全部積めたら勝ち。
2. 列の上には、1 つ小さい数で色ちがい（赤と黒）の札を重ねられる。空いた列には K だけ置ける。
3. 困ったら左上の山をめくる。この配りは必ず解ける。行きづまっても「戻す」で何手でも戻れる。

- **タップ**: 札が行ける所へ動く（置き場に置けるなら置き場、だめなら列）。
- **ドラッグ**: 札（か、表のひと続き）を指で持って好きな所へ。
- **戻す**: 1 手ずつ。長押しで続けて戻る。**ヒント**: 動かせる手を 1 つ光らせる。**全部積む**: 列が全部表で山がなくなったら出る。
- **今日の配り**: 日付で決まる配り（その人の 0 時で変わる）。番号（#268 など）が同じなら誰でも同じ札。何度でも遊べて、記録は最初に勝ったときの手数と時間。
- **ふだん**: まだ遊んでいない配りから選ぶ。勝たずに「新しく配る」を押すと負け（連勝が 0 に戻る）。
- PC: `Ctrl+Z`（戻す）、`H`（ヒント）、`Space`（山をめくる）。
- 画面の言葉は端末の言語に合わせる（日本語 / English）。メニューの「言葉」で切り替えられる。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。親のフォルダを静的サーバで開く（`/lone-deck/` の下で動かす）。

```sh
cd ..
python3 -m http.server 0 --bind 127.0.0.1   # 出た番号で http://127.0.0.1:<番号>/lone-deck/
node lone-deck/tools/test.mjs                # 決まりと解く道具の自己チェック
```

| ファイル | 中身 |
|---|---|
| `logic.js` | 決まりごと（配り・動かせる手・戻す・全部積む・行きづまり・今日の配り）。画面に触らない |
| `main.js` | 画面・操作・音・保存 |
| `i18n.js` | 画面の文字（日本語と英語） |
| `deals.js` | 解けると確かめた配りの番号（`tools/solve.mjs` が作る） |
| `tools/solve.mjs` | 配りを解く道具。`node tools/solve.mjs [数] [上限]` で `deals.js` と `tools/solutions.txt`（解き方の手順）を作り直す |
| `tools/test.mjs` | 自己チェック |

### 必ず解ける配り

配りは番号から決まる（乱数は mulberry32。同じ番号ならどの端末でも同じ配り）。`tools/solve.mjs` が番号 1 から順に解き、
解けた番号だけを `deals.js` に入れる。見つけた手順は `logic.js` の決まりで最初から当て直し、勝てると確かめてから入れる。
調べる局面の上限（20 万）までに解けなかった番号は、解けるかもしれなくても入れない。

`logic.js` の `deal` や乱数の式を変えると、一覧の番号がすべて別の配りになる。変えたら `solve.mjs` で作り直す（遊んでいる人の途中の局と記録の番号も変わるので、変えないのが基本）。

### 保存するデータ（localStorage）

| キー | 中身 |
|---|---|
| `lone-deck.settings` | 音・言葉・遊び方を見たか |
| `lone-deck.stats` | 遊んだ数・勝った数・連勝・最少手数・最短時間・遊んだ配りの番号 |
| `lone-deck.daily` | 今日の配りの日ごとの結果 |
| `lone-deck.game` | 途中の局（配りの番号と手の並び。開き直すと当て直して続きから） |
